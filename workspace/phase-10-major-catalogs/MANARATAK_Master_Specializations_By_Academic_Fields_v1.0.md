# القالب المعتمد لكل تخصص ماجستير

> يوضع هذا القالب في كل ملف تفاصيل لاحق، ويطبق على كل تخصص ماجستير دون إدخال بيانات جامعة أو برنامج مؤسسي محدد.

## 1. معلومات تخصص الماجستير الأساسية

| الحقل | المحتوى المطلوب |
|---|---|
| الرمز المرجعي | رمز `MAS` الثابت |
| الاسم بالعربية | الاسم المرجعي المعتمد |
| الاسم بالإنجليزية | الاسم المرجعي المعتمد |

| وصف مختصر | تعريف موجز مستقل عن الجامعة |

## 2. نبذة عن تخصص الماجستير

- مجال التعمق العلمي أو المهني.
- الفرق عن دراسة البكالوريوس.
- طبيعة المخرجات البحثية أو التطبيقية.
- حدود التخصص وما لا يشمله.

## 3. أنواع البرنامج الشائعة

- ماجستير بحثي — Research Master.
- ماجستير بالمقررات — Taught Master.
- ماجستير مهني — Professional Master.
- ماجستير تنفيذي — Executive Master عند ملاءمته.
- مقررات ورسالة — Coursework and Thesis.
- مشروع تطبيقي — Project Based Master.

## 4. الخلفيات الأكاديمية المناسبة للقبول

- تخصصات بكالوريوس مرتبطة مباشرة.
- تخصصات قريبة قد تقبل.
- تخصصات تحتاج مقررات استدراكية.
- خلفيات مهنية يمكن قبولها في البرامج المهنية.

> لا تدرج شروط جامعة محددة أو معدلًا أو اختبار لغة داخل Phase 10.

## 5. المتطلبات التأسيسية أو الاستدراكية العامة

- المعرفة السابقة المطلوبة.
- الرياضيات أو الإحصاء أو البرمجة عند الحاجة.
- مناهج البحث.
- المعرفة المخبرية أو السريرية.
- الخبرة المهنية العامة عند ملاءمتها.

## 6. ماذا يدرس الطالب؟

### المقررات الأساسية

تدرج الموضوعات الجوهرية المشتركة بين برامج المجال.

### المقررات الاختيارية

تدرج الموضوعات التي تحدد المسار أو التركيز.

### مناهج البحث والتحليل

- تصميم البحث.
- التحليل الكمي أو النوعي.
- أخلاقيات البحث.
- إدارة البيانات.
- الكتابة الأكاديمية.

### الجانب العملي أو التطبيقي

- المختبر.
- الاستوديو.
- التدريب السريري.
- المشروع الصناعي.
- دراسة الحالة.
- العمل الميداني، بحسب طبيعة التخصص.

## 7. المسارات والتخصصات الدقيقة

تخزن كعلاقات منظمة في `MajorTrack`، ولا ينشأ منها تخصص مستقل تلقائيًا دون مراجعة.

## 8. مكونات التخرج

قد تشمل:

- رسالة ماجستير.
- مشروع تطبيقي.
- امتحان شامل.
- تدريب مهني أو سريري.
- ملف مهني أو إبداعي.
- بحث أو عرض علمي.

## 9. المهارات المتقدمة المكتسبة

- تحليل الأدلة والأدبيات.
- تصميم البحث أو المشروع.
- استخدام أدوات المجال المتقدمة.
- حل المشكلات المعقدة.
- إدارة مشروع تخصصي.
- الكتابة والعرض العلمي أو المهني.
- اتخاذ القرار الأخلاقي.

## 10. مجالات العمل بعد الماجستير

تعرض كعلاقات مع Phase 21 Career Platform، ولا تنشئ الوظائف أو الرواتب داخل Phase 10.

## 11. أهم الوظائف المرتبطة

| الوظيفة | مدى مناسبة الماجستير | الملاحظة المهنية |
|---|---|---|
| وظيفة تخصصية متقدمة | مناسب غالبًا | قد تتطلب خبرة أو اعتمادًا إضافيًا |
| وظيفة بحثية | مناسب | بعض المسارات تفضل الدكتوراه |
| وظيفة مرخصة | غير كافٍ وحده | تخضع لترخيص الدولة والجهة المنظمة |

## 12. المسارات الأكاديمية والمهنية اللاحقة

- الدكتوراه المرتبطة.
- الزمالات البحثية أو المهنية.
- الشهادات والاعتمادات المهنية.
- التخصصات البينية الممكنة.

## 13. التخصصات المشابهة والفروق

| التخصص المشابه | الفرق المختصر |
|---|---|
| تخصص قريب | الفرق في الهدف أو المنهج أو التطبيق |

## 14. العلاقة بتخصصات البكالوريوس

- بكالوريوس مرتبط مباشرة.
- بكالوريوس مقبول غالبًا.
- بكالوريوس قد يحتاج مقررات استدراكية.

## 15. التنبيه الأكاديمي والمهني

يجب أن يوضح عند الحاجة:

- أن الماجستير لا يمنح ترخيصًا مهنيًا تلقائيًا.
- أن الماجستير المهني قد لا يعادل البحثي عند التقدم للدكتوراه.
- أن الاسم نفسه قد يختلف محتواه بين الجامعات.
- أن بعض البرامج تتطلب خبرة أو درجة مهنية أولى.
- أن المتطلبات السريرية والهندسية والقانونية تخضع للجهات المنظمة.

## 16. المصادر والتحقق

- المصادر المرجعية.
- نظام التصنيف وكوده.
- الرابط الرسمي للمصدر.
- تاريخ آخر تحقق.
- حالة المراجعة.
- المراجع أو القرارات التي دعمت الدمج أو الفصل.

# قواعد بناء القائمة

1. هذه القائمة **قاموس تأسيسي مقترح** وليست ادعاءً بوجود قائمة عالمية نهائية لتخصصات الماجستير.
2. بُنيت من قاموس البكالوريوس المرجعي لمنارتك، ثم استبعدت الدرجات المهنية الأولى والمسميات التشغيلية التي لا تتحول تلقائيًا إلى ماجستير.
3. أضيفت تخصصات دراسات عليا شائعة لا تظهر عادةً كبكالوريوس مستقل.
4. اسم الدرجة منفصل عن اسم التخصص؛ `MSc` أو `MBA` أو `LLM` نوع درجة وليس تخصصًا جديدًا بذاته.
5. لا يعني وجود التخصص في هذه القائمة أنه متاح في كل جامعة أو دولة.
6. التخصصات المتداخلة تحفظ كسجل واحد مع علاقات Cross-listing بدل التكرار.
7. يجب أن تمر القائمة بمراجعة Academic Taxonomy وARB، ثم تحقق مصدر قبل الاستيراد الإنتاجي.
8. البرامج الجامعية الفعلية وشروطها ومددها ورسومها تبقى ملكية Phase 11.

# المسميات المستبعدة من التحويل التلقائي

هذه المسميات بقيت في قاموس البكالوريوس أو الدرجات المهنية الأولى، لكنها لم تنشأ كسجلات ماجستير تلقائيًا. لا يعني ذلك استحالة وجود برنامج محلي باسم مشابه؛ بل يتطلب تحققًا منفصلًا قبل الإضافة.

| المسمى | سبب الاستبعاد |
|---|---|
| الطب والجراحة | درجة مهنية أولى وليست اسم ماجستير مرجعيًا عامًا. |
| الطب العام | درجة/مسار مهني أولي؛ تستبدل بتخصصات طبية وبحثية أدق. |
| الطب البشري | هوية درجة مهنية أولى؛ تستبدل بمسارات الدراسات الطبية العليا. |
| طب وجراحة الفم والأسنان | درجة مهنية أولى؛ تستبدل بتخصصات الأسنان العليا الدقيقة. |
| العلاج السني | مسمى أولي/تشغيلي غير مستقر كهوية ماجستير عالمية. |
| مساعدة طب الأسنان | برنامج مساعد مهني. |
| دكتور صيدلة | درجة مهنية أولى وليست ماجستيرًا. |
| تقنية العمليات الجراحية | برنامج تقني أولي؛ لا يحول تلقائيًا إلى ماجستير. |
| تقنية الطوارئ الطبية | برنامج تقني/مهني أولي؛ توجد بدائل عليا في طب الطوارئ وإدارة الطوارئ. |
| الترميز الطبي | وظيفة/مسار مهني أدق من أن يكون ماجستيرًا أكاديميًا عامًا. |
| تقنية الطب البيطري | برنامج تقني أولي؛ لا يحول تلقائيًا إلى ماجستير. |
| التمريض البيطري | برنامج مهني أولي؛ لا يحول تلقائيًا إلى ماجستير. |
| الهندسة العامة | مسمى تأسيسي عام؛ الماجستير يحتاج تخصصًا هندسيًا محددًا. |
| برمجة الحاسوب | مسمى مهاري/أولي؛ تستخدم تخصصات علوم الحاسوب وهندسة البرمجيات. |
| إدارة الشبكات | مسمى تشغيلي؛ تستخدم شبكات الحاسوب أو هندسة الشبكات أو إدارة تقنية المعلومات. |
| العلوم العامة | مسمى بكالوريوس عام وغير دقيق لملف ماجستير. |
| الطيران التجاري | تدريب وترخيص طيران أولي؛ تستبدل بدراسات إدارة وعمليات الطيران. |
| قيادة الطائرات | تأهيل وترخيص تشغيلي، وليس تخصص ماجستير أكاديميًا عامًا. |
| صيانة الطائرات | تأهيل تقني وترخيص تشغيلي؛ تستخدم هندسة الصيانة أو إدارة الصيانة عند التحقق. |
| تقنية إلكترونيات الطيران | برنامج تقني أولي؛ تستخدم إلكترونيات الطيران أو هندسة أنظمة الطيران. |

يستخدم المفتاح التالي عند الاستيراد الأولي:

```text

+ academicFieldOrDiscipline
+ degreeLevel(MASTER)
```

- Conflict.
- New Candidate.
- Rejected Candidate.

# تنبيه نهائي

هذه القائمة واسعة ومناسبة كنقطة تأسيس، لكنها ليست قائمة عالمية مغلقة. عند استيراد برامج الجامعات قد يظهر اسم جديد يكون:

- مرادفًا لتخصص موجود.
- مسارًا دقيقًا داخل تخصص موجود.
- اسم درجة لا تخصصًا.
- برنامجًا بينيًا جديدًا يستحق سجلًا مستقلًا.
- اسمًا تسويقيًا لا يستحق إنشاء تخصص جديد.

لذلك يجب أن تمر جميع الإضافات عبر Resolution + Manual Review + Governance Approval، وألا تكتب برامج Phase 11 مباشرة داخل قاموس Phase 10.
